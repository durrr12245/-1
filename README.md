# Moka Portrait Agent

A staged Codex skill for managing Moka portrait projects: identity anchors, paired front/profile beauty references, character views, environment planning, portrait series, and optional atmosphere materials.

## Included

- `SKILL.md` — entry instructions
- `references/workflow.md` — portrait, composition, detail, expression, and environment rules
- `scripts/` — project bridge and context helpers
- `agents/openai.yaml` — agent configuration

This repository contains the agent logic and workflow rules only. It does not include user photos, generated portraits, project databases, or API credentials.
